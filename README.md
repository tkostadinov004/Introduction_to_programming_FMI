# Материали от семинари по "Увод в програмирането"
*зимен семестър 2026/2027, Компютърни науки, 1 поток*

## Съдържание
- **Тема 1** - Увод. Примитивни типове данни. Оператори. Преобразуване между типовете. Булеви изрази.
- **Тема 2** - Минимално оценяване (short-circuiting). Условни конструкции - if-else, switch, тернарен оператор.
- **Тема 3** - Цикли - while, do-while, for.
- **Тема 4** - Функции.
